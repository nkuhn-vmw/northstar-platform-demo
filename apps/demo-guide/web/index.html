BEFORE YOU START

Sign in once. Connect as you.

Open Copilot and sign in with Platform SSO. Before the first prompt, open MCP connections. Connect tools that need your identity. If one says “connected, but not responding”, switch it off in your session until its credential is ready; otherwise it can interrupt chat.

KEEP HANDY

Two browser tabs.

Keep Copilot and the Market open side by side. Compare the agent’s product answers with the storefront as you present.

QUICK RECOVERY

If something stalls.

The tool needs authentication

Open Copilot’s MCP connections panel. Complete any requested browser OAuth flow for the other enabled connections. Never paste a token into chat.

{{if .HubEnabled}}
Hub returns no inventory

Confirm you authenticated against the configured Hub and that your account has access to the requested org and space. Northstar SSO access and Hub platform permissions are separate.

{{end}}
The answer looks right, but no tool ran

Ask for the named connection explicitly and inspect the tool result. A fluent answer, healthy app, or listed tool alone does not demonstrate a successful invocation.

✓
Before presenting, complete a signed-in rehearsal.

Confirm the apps are healthy, then run a real model response and an actual call through each enabled tool connection. Check memory in a new conversation. This guide describes the intended flow; it does not certify live tool results.
